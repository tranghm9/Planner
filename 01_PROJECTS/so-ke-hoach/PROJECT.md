# PROJECT — Sổ Kế Hoạch

**Sản phẩm:** artifact riêng tư https://claude.ai/artifact/Wemqe6QXbDUAJRH7dGWNHP (đã ghim lên thanh bên Claude).

**Mã nguồn:** `app/so-ke-hoach.html`; lớp tính toán Sổ nợ `app/lib/no/` (nguyên văn từ `tranghm9/FA-report`); test `tests/`.

**Tham khảo:** `02_REFERENCES/pandavocab-planner.md` (mẫu giao diện, nội dung), `02_REFERENCES/fa-report-integration.md` (quy tắc Sổ nợ).
